# sistemaos-updates

Atualizações oficiais do Sistema OS para Windows e Android.

## Downloads permanentes

- Android — APK mais recente: https://github.com/albertocodexx/sistemaos-updates/releases/latest/download/SistemaOS-Android.apk
- Windows — instalador mais recente: https://github.com/albertocodexx/sistemaos-updates/releases/latest/download/SistemaOS-PC.exe

Os dois links apontam sempre para os arquivos da atualização marcada como mais recente.

## Atualização 30.5.130 / Android 1.0.87

Esta versão corrige vulnerabilidades nas bibliotecas de processamento YAML e imagens, fixa versões seguras para evitar regressão e preserva as melhorias de assinatura rápida, parcelas da OS e consultas do Android.

- [Novidades e instaladores](https://github.com/albertocodexx/sistemaos-updates/releases/tag/v30.5.130)
- [Código-fonte do PC](https://github.com/albertocodexx/sistemaos-updates/releases/download/v30.5.130/SistemaOS-PC-Codigo-Fonte-v30.5.130.zip)
- [Código-fonte do Android](https://github.com/albertocodexx/sistemaos-updates/releases/download/v30.5.130/SistemaOS-Android-Codigo-Fonte-v1.0.87.zip)

Os pacotes de código-fonte não incluem dados de clientes, senhas, certificados privados, dependências instaladas ou caches de compilação.

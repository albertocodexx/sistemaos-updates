## Atualização 30.5.117 / Android 1.0.80

Troca rápida imediata com renovação segura de sessão expirada no processo novo, sem depender do lock do cliente anterior, e sincronização entre computadores corrigida com paginação completa e recuperação automática de OS ausentes. O Android 1.0.80 permanece como o APK oficial desta publicação.

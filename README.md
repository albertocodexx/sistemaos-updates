Baixe somente pelos canais oficiais da Aurevion. A disponibilidade de um instalador público não dispensa conta e assinatura válidas para utilizar os serviços do Sistema OS.

## Política de publicação

Publicar somente instaladores EXE/APK, blockmaps, checksums e manifestos de atualização revisados. Nunca enviar fontes, ZIPs de desenvolvimento, bancos, backups, certificados, chaves, senhas, configurações privadas, logs ou dados de clientes. Não habilitar builds de código privado em Actions deste repositório público.

Integração IA — Classificação de Pagamento (Groq)

Quando o cliente escolhe pagamento manual e digita livremente como vai pagar (ex.: "vou pagar na maquininha da stone"), a IA lê a mensagem e identifica automaticamente a forma de pagamento, sem depender só de uma lista fixa de palavras. Se a IA não estiver configurada, ou não conseguir responder por qualquer motivo, o sistema usa automaticamente o classificador por palavras-chave como reserva — o cliente sempre recebe a confirmação de que a forma de pagamento dele foi registrada.

Obtenha gratuitamente em: console.groq.com → API Keys → Create API Key

Desmarque para usar apenas o classificador por palavras-chave, mesmo com uma chave configurada.

Integração IA — Assistente de Chat

Escolha o provedor do assistente que consulta OS, clientes, estoque e financeiro. As chaves ficam protegidas pelo cofre do Windows e nunca aparecem novamente em texto aberto.

Apenas a chave do provedor selecionado será solicitada.

Backup Automático

O sistema faz backup automático diário de todos os dados: ordens de serviço, estoque, peças, clientes e configurações da empresa (logo, tema, dados cadastrais, termos, etc.). São mantidos os últimos 15 backups automáticos.

Backup manual: exporta um arquivo .json para você guardar onde quiser, ou restaura um backup existente (os dados do arquivo são mesclados com os atuais, nada é apagado).

Importar Lote do Celular

Recebeu um arquivo .json exportado do app do celular? Clique em "Selecionar Arquivo" — o sistema aceita tanto um lote com várias OS/Compras/Vendas misturadas quanto uma OS exportada avulsa (formato antigo). Cada item é criado normalmente (número oficial e PDF gerado automaticamente, já com a assinatura correspondente incluída). Itens já importados antes são detectados e pulados automaticamente.

Assinatura Recebida do Celular

Depois de enviar uma OS, Venda ou Compra pelo botão " Enviar para assinatura no celular" (disponível na tela de cada documento) e o cliente assinar no celular, importe aqui o arquivo .json de resposta — a assinatura é gravada de volta no mesmo documento (nenhum documento novo é criado).

Zona de Risco

Zerar Sistema apaga permanentemente todas as Ordens de Serviço, Orçamentos, Estoque (aparelhos e peças), Compras, Pagamentos, Reembolsos, Cobranças e logs de mensagens/movimentações. Os contadores voltam a começar do início (OS-0001, etc.).

Configurações da empresa, usuários e cargos NÃO são apagados. Antes de zerar, o sistema faz um backup automático de segurança e pede a senha de exclusão para confirmar.

Atualização do Sistema

O Sistema OS verifica atualizações seguras pelo GitHub. Quando houver uma versão nova, ela será baixada em segundo plano; seus dados locais serão preservados.

1. Visao Geral do Sistema

O Sistema OS e uma aplicacao desktop desenvolvida em Electron para gerenciamento completo de assistencias tecnicas. Centraliza ordens de servico, estoque de aparelhos, emissao de documentos PDF, controle financeiro e backup automatico dos dados.

Principais Funcionalidades

  • Ordens de Servico (OS): criacao, edicao, acompanhamento de status e geracao automatica de PDF.
  • Checklist Tecnico: registro de defeitos, acessorios recebidos, testes de entrada e diagnostico com orcamento estimado.
  • Estoque de Aparelhos: cadastro de aparelhos para revenda, com checklist, fotos, financeiro e comprovante de venda.
  • Compras de Aparelhos: contratos de compra de terceiros (pessoas fisicas) com geracao de PDF.
  • Calculo de Lucro: percentual de lucro com preco sugerido calculado automaticamente.
  • Backup Automatico: backup diario com retencao dos ultimos 15 arquivos.
  • Permissoes: cargos configuráveis por modulo, bloqueio de usuarios e senha de exclusao com auditoria.
  • Painel: estatisticas, graficos e resumo financeiro.

2. Instalacao e Primeiro Acesso

Requisitos do Sistema

  • Windows 10 ou superior (64 bits recomendado)
  • Node.js 18 ou superior (modo desenvolvimento)
  • Ou o instalador .exe gerado pelo Electron Builder (producao)

Instalacao em Modo Desenvolvimento

  1. Extraia o arquivo do projeto em uma pasta.
  2. Abra o terminal na pasta do projeto.
  3. Execute: npm install
  4. Para iniciar: npm start

Gerando o Instalador (Producao)

  1. No terminal da pasta do projeto, execute: npm run build
  2. O instalador sera gerado em dist\.
  3. Distribua o arquivo .exe para os usuarios.
Importante: Os dados ficam em Meus Documentos/Sistema OS, nunca dentro da pasta do programa. Atualizar ou reinstalar o sistema nao apaga seus dados.

Primeiro Acesso

Ao abrir pela primeira vez, o sistema cria o banco de dados vazio e solicita que voce configure os dados da empresa antes de continuar.

3. Configuracoes Iniciais

Clique no botao Configuracoes no topo da tela para abrir o painel de configuracao.

Dados da Empresa

  • Nome da empresa: aparece no cabecalho de todos os PDFs.
  • Endereco e Telefone: exibidos nos documentos.

CNPJ

Ative a opcao "Possuo CNPJ" para inserir o CNPJ. Escolha se ele aparece ou nao nos documentos PDF.

Lucro Padrao

Define o percentual de lucro padrao usado ao criar novas OS ou calcular preco de venda no estoque. Pode ser sobrescrito individualmente em cada OS ou item.

Logo da Empresa

Faca upload de uma imagem (PNG, JPG) para aparecer no cabecalho dos PDFs. Tamanho recomendado: 300x100 px ou proporcional.

Permissoes de Exclusao

Defina uma senha opcional. Quando configurada, qualquer exclusao de OS ou item do estoque exigira essa senha e o nome do responsavel, registrado em historico.

Tema e Cores

Personalize as cores da interface e dos PDFs. Consulte a secao 11 para detalhes.

Backup Automatico

Esta secao mostra os ultimos backups gerados. Use o botao Fazer Backup Agora para backup imediato ou baixe qualquer backup listado.

4. Ordens de Servico (OS)

Criando uma Nova OS

  1. Clique em Nova OS no topo da tela.
  2. Preencha os dados do cliente: nome, telefone, CPF (opcional), e-mail.
  3. Informe o aparelho: tipo, marca, modelo, cor, IMEI, senha do aparelho, acessorios e defeito relatado.
  4. No card Orcamento e Lucro, informe o valor investido e o percentual de lucro. O preco sugerido e calculado automaticamente.
  5. Revise os termos da OS (pre-preenchidos com o padrao configurado).
  6. Clique em Salvar e Gerar PDF.
O numero da OS e gerado automaticamente em ordem crescente (EST-0001, EST-0002...) e nao pode ser alterado.

Editando uma OS

Na lista de OS, clique em Editar na linha desejada. Voce pode alterar todos os campos, incluindo o status. Ao salvar, o PDF e regenerado automaticamente.

PDF da OS

Gerado automaticamente ao criar ou editar uma OS. Para abri-lo, clique em Ver PDF. Para regenerar manualmente, use o botao Gerar PDF.

Excluindo uma OS

Clique em Excluir na linha da OS. Se uma senha de exclusao estiver configurada, ela sera solicitada junto com o nome do responsavel.

A exclusao de uma OS e permanente e nao pode ser desfeita.

Pesquisa e Filtros

Use o campo de busca para filtrar por nome, numero de OS, IMEI, marca ou modelo. A busca e em tempo real.

5. Checklist Tecnico e Diagnostico

Ao criar ou editar uma OS, o sistema disponibiliza ferramentas de diagnostico divididas em tres abas: Defeitos, Acessorios Recebidos e Testes de Entrada, alem da secao de Diagnostico Tecnico.

Checklist de Defeitos

Disponivel para Notebook e Computador Desktop / All In One. A lista e adaptada automaticamente ao tipo de equipamento. Para outros tipos (Smartphone, Tablet etc.), use o campo livre de defeito relatado.

Acessorios Recebidos

Registre os itens fisicos entregues junto ao equipamento: Carregador, Fonte, Mouse, Teclado, Mochila, Bolsa, Cabos, Adaptador etc. Esses dados aparecem no PDF da OS como comprovante de recebimento.

Testes de Entrada

Registre os testes realizados no recebimento: Liga normalmente, Carrega bateria, Imagem, Audio, USB, Rede, Wi-Fi, Webcam, Touchpad e Teclado. Documentam o estado do aparelho no momento do recebimento.

6. Estoque de Aparelhos

O modulo de Estoque gerencia aparelhos comprados pela assistencia para revenda, incluindo pecas e componentes. Acesse pela aba Estoque.

Cadastrando um Aparelho

  1. Clique em + Novo Aparelho.
  2. Se o aparelho veio de um contrato de compra, informe o número no campo Compra vinculada. Você pode digitar 1 ou 0001; o sistema transforma em CP-0001 e sincroniza aparelho e custos.
  3. Na aba Dados, preencha marca, modelo, cor, IMEI, tipo e condicao.
  4. Na aba Checklist, marque os itens testados.
  5. Na aba Financeiro, informe o valor pago, custo de pecas (se houver), extras e percentual de lucro. O sistema calcula o preco sugerido de venda automaticamente.
  6. Na aba Fotos, adicione fotos do aparelho (ate 5 fotos).
  7. Clique em Salvar.

Cadastrando uma Peca, Consumivel ou Acessorio

  1. Clique em + Novo Item na aba de pecas e consumiveis.
  2. Escolha entre Peca / Componente, Consumivel ou Acessorio.
  3. Cadastre itens como pelicula, carregador, cabo USB, fonte, cola ou material de limpeza.
  4. Depois do cadastro, use os botoes Entrada e Saida para alterar o saldo com historico e motivo.
  5. Use Excluir somente quando o item nao deve mais existir no cadastro.
  6. Informe o valor pago e o preco de venda desejado.
  7. Clique em Salvar.

Registrando uma Venda

  1. Abra o aparelho no estoque e mude o status para Vendido.
  2. A aba Venda sera exibida automaticamente.
  3. Preencha os campos obrigatorios: nome do comprador, telefone, valor, data e garantia.
  4. Clique em Salvar e depois em Comprovante de Venda para gerar o PDF.

Filtros Rapidos

Use os botoes de filtro acima da lista para exibir apenas aparelhos por status, ou clique em Pecas para listar somente pecas e componentes.

7. Compras de Aparelhos

Registra a aquisicao de aparelhos de terceiros (pessoas fisicas), gerando contrato formal de compra e venda. Acesse pela aba Compra de Aparelhos.

Registrar Nova Compra

  1. Clique em + Nova Compra.
  2. Preencha os dados do vendedor. O nome é obrigatório; CPF e telefone são opcionais.
  3. Informe os dados do aparelho: tipo, marca, modelo, cor, IMEI, capacidade e estado de conservacao.
  4. Preencha os dados da compra: valor pago, forma de pagamento e data.
  5. Adicione observacoes e condicoes, se necessario.
  6. Clique em Salvar. O contrato em PDF e gerado automaticamente.

PDF do Contrato de Compra

Gerado ao salvar, o contrato inclui: número do contrato, dados disponíveis do vendedor, dados do aparelho, valor pago, forma de pagamento, data e espaço para assinaturas. Os PDFs ficam em Sistema OS\PDFs-Compra\.

As cores do cabecalho e titulos do PDF de compra seguem automaticamente o tema configurado em Configuracoes, mantendo identidade visual consistente.

8. Backup e Restauracao

Backup Automatico Diario

O sistema faz backup automatico uma vez por dia em Documentos\Sistema OS\BACKUP - OS\auto\. Sao mantidos os ultimos 15 backups — os mais antigos sao removidos automaticamente.

Backup Manual

  • Backup: exporta todos os dados em um arquivo JSON. Escolha onde salvar.
  • Restaurar: importa dados de um arquivo de backup. Registros duplicados sao ignorados automaticamente.

Estrategia de Backup Recomendada

  1. Diario (automatico): o sistema ja faz sozinho na pasta local.
  2. Semanal (manual): exporte via botao "Backup" e salve em OneDrive ou Google Drive.
  3. Mensal: guarde uma copia em HD externo ou pen drive fora do local.
Backups so tem valor se estiverem em local diferente do computador principal.

9. Permissoes e Exclusao

Senha de Exclusao

Configure em Configuracoes > Permissoes de Exclusao. Quando configurada, toda exclusao de OS, item do estoque ou contrato exigira a senha e o nome do responsavel, gravados em historico de auditoria.

Historico de Exclusoes

Todas as exclusoes sao registradas em database.json no campo historicoExclusoes, com: ID excluido, data, responsavel e dados resumidos do registro removido.

Sem senha configurada: qualquer usuario pode excluir registros. O nome do responsavel ainda sera solicitado para fins de registro.

Tipos de PDF Gerados

  • PDF de OS: gerado ao criar ou editar. Inclui dados do cliente, aparelho, checklist, diagnostico, termos e logo da empresa.

  • Contrato de Compra: gerado ao salvar ou reabrir contrato. Inclui dados do vendedor (com CPF), aparelho, valor, forma de pagamento e assinaturas.

12. Usuarios, Cargos e Permissoes

Acesse via botao Usuarios ou Cargos no topo da tela (visivel apenas para quem tem permissao de usuarios).

Gerenciamento de Usuarios

  • Novo Usuario: cria usuario com login, senha e cargo.
  • Gerar Automaticamente: gera usuario com credenciais aleatorias.
  • Editar: altera nome e cargo do usuario.
  • Bloquear / Desativar: impede o acesso sem excluir o usuario.
  • Reativar: restaura o acesso de usuario bloqueado ou inativo.
Usuarios nao podem ser excluidos permanentemente — apenas bloqueados ou desativados. Isso preserva o historico de OS e acoes vinculadas ao usuario.

Cargos e Permissoes

Os cargos definem quais modulos cada usuario pode acessar. O sistema vem com 4 cargos de fabrica:

CargoAcesso padrao
AdministradorAcesso total — nao pode ser editado ou excluido
GerenteAcesso total — permissoes editaveis
TecnicoOS, Clientes, Estoque, Relatorios
AtendenteOS e Clientes

Cargos Personalizados

Em Cargos, clique em + Novo Cargo Personalizado para criar cargos com permissoes especificas por modulo: OS, Estoque, Financeiro, Relatorios, Configuracoes, Usuarios.

Cargos de sistema (Gerente, Tecnico, Atendente) podem ter suas permissoes editadas, mas nao podem ser excluidos enquanto houver usuarios vinculados. O cargo Administrador e fixo e nao pode ser alterado.

13. Resolucao de Problemas

O sistema nao abre

  • Verifique se o Node.js esta instalado: node --version no terminal.
  • Execute npm install na pasta do projeto antes de npm start.

PDF nao e gerado

  • Verifique se Documentos\Sistema OS\PDFs\ existe e tem permissao de escrita.
  • O antivirus pode bloquear a criacao de arquivos — adicione a pasta a lista de exclusoes.

Banco de dados corrompido

Se o banco for corrompido, o sistema faz backup do arquivo danificado com sufixo .corrompido-TIMESTAMP.bak e recria o banco vazio. Restaure com um backup via botao Restaurar.

Erro ao importar backup

  • Certifique-se de que o arquivo e um backup gerado pelo proprio Sistema OS.
  • Registros duplicados sao ignorados silenciosamente — comportamento esperado.

Fotos nao aparecem no estoque

As fotos sao copiadas para Documentos\Sistema OS\Fotos-Estoque\. Se o banco for restaurado em outro computador, as fotos precisam ser copiadas manualmente.

Usuario nao consegue acessar uma aba

Verifique o cargo do usuario em Usuarios e confirme se o modulo correspondente esta habilitado no cargo dele via Cargos.

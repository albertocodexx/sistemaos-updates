# Sistema OS Android 1.0.85

- Corrige documentos enviados para assinatura que voltavam após serem excluídos e o aplicativo ser reiniciado.
- Mantém uma exclusão local durável mesmo sem internet e repete a confirmação na nuvem automaticamente.
- Impede que uma cópia ainda pendente no servidor seja importada novamente.
- Apaga do aparelho os dados pessoais e assinaturas assim que o usuário confirma a exclusão.
- Melhora o alinhamento da logo nos PDFs de OS, venda, compra e garantia.
- Compatível com o Sistema OS para Windows 30.5.125.

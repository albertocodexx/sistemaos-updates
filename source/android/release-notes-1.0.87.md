# Sistema OS Android 1.0.87

- Move a consulta das autorizações de desbloqueio para a aba Consultas.
- Mantém a aba Desbloqueios dedicada à criação e edição de autorizações.
- Permite abrir ou editar uma autorização encontrada pela busca de cliente, número ou aparelho.
- Recebe as parcelas criadas na OS do computador, com valor dividido e vencimento de cada parcela.
- Compatível com Sistema OS Windows 30.5.129.
